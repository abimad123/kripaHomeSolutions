# Kripa Home Solutions

A responsive, modern, multi-page **Product Catalog Website** built for **Kripa Home Solutions** (based in Kollam, Kerala), designed to showcase premium building materials, modular kitchens, sanitaryware, electrical fittings, and paints.

Developed with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**, this project delivers a highly interactive, smooth, and user-focused experience with comprehensive **client-side** and **admin-side** functionalities.

---

## Features

- **Multi-Category Product Catalog:**
  Explore building materials, modular kitchens, and more with an intuitive interface. Features dedicated routing for different product categories.

- **Product Comparison Hub:**
  Users can seamlessly select multiple products and compare them side-by-side using the built-in Comparison Modal.

- **Dynamic Search & Filtering:**
  Quickly find products with a smart search bar and robust category filters.

- **Product Enquiry System:**
  Users can send direct enquiries for specific items, complete with automated prefilled details.

- **Comprehensive Admin Dashboard:**
  A secure custom admin panel featuring:
  - Product Manager (CRUD operations for the catalog)
  - Media Manager 
  - Inquiry tracking
  - Subscriber management

- **Modern UI/UX & Animations:**
  Built with **Tailwind CSS** and animated using **Framer Motion** for a premium, highly interactive feel. Features **Dark Mode** support that respects system preferences.

- **SEO Optimized:**
  Includes dynamic SEO components and structured data (Schema.org) for better discoverability of the local business.

- **Fully Responsive Design:**
  Optimized layouts that scale beautifully across mobile, tablet, and desktop devices.

---

## Tech Stack

- **Framework / Core:** React 19, Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion, @lottiefiles/dotlottie-react
- **Routing:** React Router DOM (v6)
- **Icons:** Lucide React
- **Deployment & Hosting:** Vercel

## Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository** (or download the source code):
   ```bash
   git clone <repository-url>
   cd kripasolutions
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open the app:**
   Open `http://localhost:5173` (or the URL provided in your terminal) to view it in your browser.

### Building for Production

To build the application for production, run:
```bash
npm run build
```
The optimized files will be generated in the `dist` folder, ready for deployment.
